# Интерфейсы — Елизавета Цех

Статическая ветка сайта, доступная на `/interfaces/`.

## Рабочая часть

- `index.html` — входная страница;
- `support.js` — среда выполнения компонентов `<x-dc>` и `<dc-import>`;
- `NewCasesClean.dc.html` и вложенные `New*.dc.html` — интерактивные кейсы;
- `case-reel.js`, `dash-reel.js`, `original-deck-reel.js` — анимированные
  превью;
- `cover-demo-*.html`, `CoverDemo*.dc.html` — обложки кейсов;
- `hero-export/`, `hero-slides/`, `assets/`, `deck/`, `img/` — используемые
  медиа и ресурсы.

## Архив

`trash/` хранит предыдущие версии компонентов, старые анимации, исходники и
загрузки. Эти файлы не используются текущей страницей и намеренно не публикуются
nginx. Не удаляйте их без отдельной проверки истории и ссылок.

## Локальный просмотр

Запустите `Запустить.command` и откройте `http://localhost:8765/`.
