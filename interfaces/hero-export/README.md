# Hero reel

Статичный HTML + vanilla JS, без зависимостей.

- index.html — разметка (блок #hero-reel внутри section.hero)
- hero-reel.js — анимация (Web Animations API), цикл 19 с
- img/ — скриншоты

Встраивание: скопируйте div#hero-reel в контейнер с position:relative и нужной высотой, подключите hero-reel.js после разметки, шрифт Manrope.
