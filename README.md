# Лиза Цех — запуск сайта

Сайт раздаётся Python-сервером из этой папки только по пути `/portfolio/`.
Он не использует 80, 443 или 8080: по умолчанию HTTPS-сервер слушает
все интерфейсы на `8443`.

## Запуск

На сервере из папки проекта:

```bash
python3 server.py
```

Сертификаты по умолчанию берутся из:

```text
/etc/letsencrypt/live/s883238.foxcdn.net/fullchain.pem
/etc/letsencrypt/live/s883238.foxcdn.net/privkey.pem
```

Если сертификат находится в другой папке, укажите её без изменения кода:

```bash
SSL_CERT_PATH=/etc/letsencrypt/live/your-domain python3 server.py
```

Проверка на самом сервере:

```bash
curl -kI https://127.0.0.1:8443/portfolio/
```

## Публичный адрес

После открытия TCP-порта `8443` в firewall публичный адрес будет:

```text
https://domain:8443/portfolio/
```

Путь `/portfolio/` обязателен: запрос на `/portfolio` автоматически
перенаправляется на вариант со слешем.

Адрес строго в виде `https://domain/portfolio/` невозможен, пока 443 занят:
один IP-порт может принимать соединения только одним процессом. Для адреса
без `:8443` потребуется изменить уже работающий сервис, владеющий 443;
отдельному Python-серверу это сделать нельзя.
